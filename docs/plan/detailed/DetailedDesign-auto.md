# 自律測定の移動

[DetailedDesign.md](DetailedDesign.md) の詳細。**自律測定の移動（配置図 → 盤の選択 → 盤から盤への移動 → 盤前の作業への引き渡し）を、実装できる形に落とす。**
入力は [Spec-auto.md](../spec/Spec-auto.md)・[Spec.md](../spec/Spec.md) §1.1.2・§1.2 と、th-system [DetailedDesign-measure.md](../../../../th-system/docs/plan/detailed/DetailedDesign-measure.md)（th との名前と形の正）。
盤前で腕を起こしてから格納するまで（測定機構の制御。[Spec-arm.md](../spec/Spec-arm.md)）は**ここでは扱わない**（§1.3 の「測定機構の口」の向こう側）。
名前はすべて [-names.md](DetailedDesign-names.md)（`DD-1`）、値と出どころは [-names.md](DetailedDesign-names.md) §5（`DD-3`）。

**状態: 確定（2026-11-11 ユーザー。2026-11-04 初版）。§2.6（背面側への回り込み）は 2026-11-23 ユーザー確定。**立った問いと答えは [-open.md](DetailedDesign-open.md) §1。

> **2026-11-14（ユーザー決定）: 腕の伸縮を無くし（機体の中心から測定器まで 1760 mm で固定）、点ごとに旋回と前後の並進で合わせることになった**（[Spec-auto.md](../spec/Spec-auto.md) §1）。目的地として向かう立ち位置は今までどおり 1 盤につき 1 か所で、点ごとの旋回と前後の並進は「測定機構の口」の向こう側（盤前の作業）なので、**ここの移動の設計は変わらない**。盤前の作業の詳細設計を書くときに、前後の並進（th-system への申し送り。名前と形は th が書く）を入れる。
> **同日（ユーザー決定）: 「測定機構なしの道」（§2.3。測定機構が付いていなければ移動して盤前の作業を飛ばす）は、仕様でやめた**（[Spec-auto.md](../spec/Spec-auto.md) §7。本システムは使われているとき測定機構が付いているとみなし、アームの制御器と通信できないときは何も動かさない。昇降部も「付いていない」を出さなくなった）。**ただし測定機構を搭載するまでは、移動を確かめるためにこの制限をバイパスでき、既定はバイパス**（同日ユーザー決定。デモ特例 [EXCEPTION-LEDGER.md](../EXCEPTION-LEDGER.md) `W-1`）。バイパス中の振る舞いは測定機構なしの道と同じなので、**§2.3 の道は残し、入り口を昇降機の口の「付いていない」から本システムの設定に替える。直すのは `WP-AUTO-07`**（[ImplementationPlan.md](../ImplementationPlan.md) §4）。
> **2026-11-15（ユーザー決定）: 盤への移動は精度が出ないものとし、着いたあとは直接制御の動きで合わせる**（[Spec-arm.md](../spec/Spec-arm.md) §2・[Spec-auto.md](../spec/Spec-auto.md) §1・§6）。**着いたあと目的地を出し直す決まり（`needs_regoal`・飛ばす理由 `stand_mismatch`）は仕様でやめ、`WP-AUTO-08` で外した**（2026-11-23 マージ `cbb3dde`）。
> **2026-11-23（ユーザー決定）: 奥の点が正面側から届かない盤は背面側へ回り込む。基本は正面側をすべて測ってから背面側。奥行きが測れていない盤も背面側で確かめる。たどり着けなければ奥の 2 隅は「届かず」**（[Spec-auto.md](../spec/Spec-auto.md) §1〜§3）。**移動の側の設計は §2.6（2026-11-23 ユーザー確定）。直すのは `WP-AUTO-10`。**同日の排気口のカバーを避ける決まり（[Spec-arm.md](../spec/Spec-arm.md) §2）は盤前の作業の側（測定機構の口の向こう）なので、ここでは扱わない（[-open.md](DetailedDesign-open.md) §2 に申し送り）。

### 1.2 機能側の中身

| 部分 | 中身 |
| --- | --- |
| `fk_auto.core` | **純関数だけ**（§3・§4）。ROS 2 にも通信にも触れない。ホストで試験する |

## 2. 状態機械（`fk_auto.runner`）

### 2.1 段

| 段 | すること | 次へ |
| --- | --- | --- |
| `IDLE` | 自律測定の外。生存確認だけ出す | 画面が `auto.begin` を送り、th が `AUTO_MEASURE` → `PREPARE` |
| `PREPARE` | 腕が格納位置か・昇降機の原点が取れているかを確かめる。原点が無ければ下端まで下げる（関門を通す） | 済み → `SURVEY`。下げられない → `HALTED` |
| `SURVEY` | ss に全周を依頼し、結果を地図の座標に直して配置図にする（§3 `to_map`・`front_edge`）。**後片付けの完了まで待つ**。結果が使えない（§3 `ss_result_valid`）ときは依頼し直す（`ss_retry_max` 回まで） | 完了 → `SELECT`。**途中で終わった結果（時間切れ・人の操作で中断など）も、返った盤と見た範囲を配置図に使う**（見ていない方向として示せる）。結果が来ない・使える結果が得られない → 取り消して後片付けを待ち、**空の配置図で `SELECT`**（理由を画面に出す。「もう一度探す」で探し直せる） |
| `SELECT` | 人が盤を選んで「開始」（`auto.start`）するのを待つ。「もう一度探す」（`auto.rescan`）→ `SURVEY` | 開始 → 回る順を決めて（§3 `order_panels`）`LOWER` |
| `LOWER` | 昇降機が下端でなければ下げる | 下端 → `GOAL`。下げられない → `HALTED` |
| `GOAL` | 立ち位置（§3 `stand_pose`）へ `meas.goal`。`BLOCKED` が `blocked_wait_s` 続いたら `meas.reroute`（`reroute_max` 回まで） | `ARRIVED` → `RECHECK`。解けない → `meas.abort` → 飛ばす（`no_path`）。立てない（§3 `stand_blocked`）→ 出さずに飛ばす（`stand_blocked`） |
| `RECHECK` | その盤の方向を ss に依頼して認識し直し、配置図を直す（**その盤とみなすのは、配置図の中心から `recheck_match_max_m` 以内で最も近い矩形。無ければ `top_not_found`**。2026-11-11。隣の盤を取り違えないため）。結果が使えなければ依頼し直す（`ss_retry_max` 回まで） | その盤とみなす矩形が選べた → **許容差を見ずに `AT_PANEL`**（着いたあとの位置合わせは盤前の作業の側。2026-11-15。WP-AUTO-08 で目的地の出し直しを外した）。見つからない → 飛ばす（`top_not_found`）。ss が「必要な高さまで上がれない」を返した → 飛ばす（`camera_too_low`）。「天井までの距離が分からず上がれない」→ 飛ばす（`ceiling_unknown`）。「カメラの向きが分からない」→ 飛ばさず `PAUSED`（§2.4）。時間切れ・使える結果が得られない → 取り消して後片付けを待ち、飛ばす（`ss_failed`） |
| `AT_PANEL` | 測定機構の口に盤前の作業を渡し、結果を待つ | 結果を記録 → 次の盤の `LOWER`。全部済み → `FINISH`。**2026-11-23: 回る単位は「盤と側」。正面側の作業のあと背面側の訪問を足すことがある（§2.6）** |
| `FINISH` | 昇降機を下げ、最後の盤の前で待つ。結果の一覧を出す | 人が選び直して「開始」→ `LOWER` |

**飛ばす** = 理由を結果に残して次の盤へ（[Spec-auto.md](../spec/Spec-auto.md) §6）。理由の名前は -names.md §4.3。

### 2.2 割り込み（どの段からでも）

| 起きたこと | 振る舞い | 戻り方 |
| --- | --- | --- |
| th が `PAUSE`（人のジョグ・回復フォルト・通信途絶・§4.2 の停止） | `PAUSED`。**自分からは発進しない** | 人の「走行」（`auto.run`）→ §3 `can_run` が通れば `meas.start`。`GOAL` はそのまま続く。**`RECHECK` は、その段の頭からやり直す**（機体が動いたかもしれないため）。**`AT_PANEL` の間の一時停止は測定機構の口に知らせるだけにし、どうするかは測定機構の側で決める（未決。腕が出ている途中でジョグされたときの扱いは仕様に無い）** |

| **th が動く指示を拒否した**（2026-11-11 ユーザー承認。[Spec-auto.md](../spec/Spec-auto.md) §6）。**th の `/measure/command` が見えない・応答が得られないときも同じに扱う（理由 `th_unreachable`）。指示を溜めて後で送らない**（関門を通した時点と送る時点がずれ、その間に様子が変わっても送ってしまうため。2026-11-11） | **自分からは出し直さない。**理由は `AutoState.th_reject_reason` に出す。`localization_lost`・`map_mismatch` → `REENTRY`（地図か配置図が古い）。`meas.goal` のほかの理由（`corner_obstacle` など）→ `SELECT` に戻る（th は `WAIT` のまま。測り終えた盤の結果は残す）。`meas.start` → `PAUSED` のまま。`meas.reroute` → 再計算 1 回の失敗として数える（`reroute_max` を超えたら `meas.abort` → 飛ばす `no_path`）。止める側（`meas.stop`・`meas.abort`・`meas.finish`）が拒否されたら、th の状態で止まっていると分かれば待たずに進む（結果は来ない） | 人が選び直して「開始」／もう一度「走行」 |
| 人の「終了」（`auto.finish`） | 腕が格納位置になければ、画面で確認が済んだ印（`arm_confirmed`）が要る。**腕の状態が読めないときも、格納位置にないのと同じに確認を求める**。`meas.finish` → `IDLE` | — |

**WP-AUTO-03 の実装で決めたこと（2026-11-11。設計どうしの食い違いと、書いていなかった細部）**

| 場面 | 決めたこと |
| --- | --- |

### 2.4 ss の口の版 2 の扱い（2026-11-16。[Spec-auto.md](../spec/Spec-auto.md) §3）

| 場面 | 振る舞い |

| `SURVEY` で `ceiling_unknown`・`camera_pose_unknown` | ほかの途中の終わり方と同じ。返った盤と見た範囲を配置図に使い、理由を `survey_reason` に出す（「もう一度探す」で探し直せる） |

| `RECHECK` で `camera_pose_unknown` | **後片付けの完了を受けてから `PAUSED`。返った盤があっても使わず、飛ばさない。**`gate_reason` に `camera_pose_unknown` を出し続ける。人の「走行」（`auto.run`）で `RECHECK` の頭からやり直す（th は `WAIT` のままなので `meas.start` は出さない。依頼は関門を通す）。自分からは依頼し直さない |

### 2.5 ss の口の本物（`RosSsPort`。2026-11-18。WP-AUTO-06）

名前と形は ss [DetailedDesign-names.md](../../../../ss-system/docs/plan/detailed/DetailedDesign-names.md) §3・§9a（版 `"3"`）。型は ss `fa2593c` から取り込む（[DetailedDesign-names.md](DetailedDesign-names.md) §7）。

| 場面 | 振る舞い |

**奥行きを測れていない盤（[Spec-auto.md](../spec/Spec-auto.md) §3。`depth_measured` が false）**:

| 場面 | 振る舞い |
| --- | --- |

### 2.6 背面側への回り込み（2026-11-23 ユーザー確定。WP-AUTO-10。[Spec-auto.md](../spec/Spec-auto.md) §1〜§3）

**回る単位を「盤」から「訪問」（盤と側。側は `front`／`back`）に替える。**段（§2.1）は増やさない。`LOWER` → `GOAL` → `RECHECK` → `AT_PANEL` を訪問ごとに回す。

| 場面 | 振る舞い |
| --- | --- |
| 開始（`auto.start`） | 選ばれた盤の**正面側の訪問だけ**を `order_panels` の順で並べる（今までどおり） |
| 背面側が要るか | **正面側の `AT_PANEL` が終わったとき**（済み・`arm_space_blocked`・`no_mechanism` のどれでも）、認識し直した盤で §3 `needs_back` を呼ぶ。真なら、その盤の背面側の訪問を「背面側の待ち」に足す。**正面側の `AT_PANEL` に届かなかった盤（`no_path`・`stand_blocked`・`top_not_found` など）には足さない**（2026-11-23 ユーザー決定。[-open.md](DetailedDesign-open.md) §1 #6）。**測定機構なしの道（バイパス）でも足す**（移動を確かめるため。背面側の結果も `no_mechanism`） |
| 背面側の順 | **正面側の訪問をすべて終えたとき**、今の位置から §3 `order_back` で背面側の待ちを並べ、続けて回る（仕様「移動距離が短くなるように。基本は正面側をすべて測ってから背面側」） |
| 背面側の立ち位置 | §3 `back_stand_pose`。立てるかは今までどおり `stand_blocked` |
| 背面側の認識し直し（`RECHECK`） | ss への依頼は正面側と同じ（その盤の方向）。**その盤とみなすのは §3 `match_back` で選んだ矩形**（正面側の `recheck_match_max_m` の決め方は、奥行きが分からないと背面側では中心がずれるので使わない）。選べたら §3 `merge_back` で配置図の盤を直す（奥行きと中心。正面の向きは変えない）。返った理由の扱い（`camera_too_low`・`ceiling_unknown`・`camera_pose_unknown`・`ss_failed`）は正面側と同じ |
| 背面側の結果 | `PanelResult` に側（`back`）を付けて残す。**背面側の訪問が飛ばされた（`no_path`・`stand_blocked`・`top_not_found` など）ときは、奥の 2 隅は「届かず」**（仕様 §1・§3。理由はそのまま残し、画面で「奥の 2 隅: 届かず」と示す）。正面側の結果は消さない |
| 一時停止・中止・入り直し | 今までどおり（§2.2）。中止で外れた背面側の訪問は結果を残さない。**入り直しで配置図を作り直したら、背面側の待ちも捨てる** |
| 盤前の作業に渡すもの | 盤と側。**どの点を測るかは測定機構の側が決める**（正面側: 中央と手前の 2 隅。`needs_back` が偽なら奥の 2 隅も。背面側: 奥の 2 隅＝機体から見て手前の 2 隅）。最初の版は測定機構なしなので渡さない |

### 2.3 測定機構なしの道

昇降機の口が「測定機構が付いていない」を返す間は、`AT_PANEL` で作業を渡さず、結果を「飛ばした・`no_mechanism`」にする。
腕の条件（格納位置にあるか）は満たしているとみなす（[Spec-auto.md](../spec/Spec-auto.md) §7）。**最初の版の結合試験（WP-AUTO-03）はこの道で 1 盤・複数盤を通す。**

## 4. 関門と見張り

### 4.1 関門（`gate(command, snapshot)`）

**th への指示と昇降機への命令は、すべてここを通す。**通らなければ送らず、理由を状態に出す。

| 出すもの | 通す条件（どれか 1 つでも欠ければ出さない） |
| --- | --- |
| `meas.goal`・`meas.start` | th の様子が読める（`th_status_stale_ms`）／昇降機が下端に着いている（高さが読める）／腕が格納位置にある（読めて。測定機構なしを除く）／ss の依頼が終わっている（後片付けの完了まで。**ss の状態が `IDLE` で読めること。本システム以外の依頼も含む**）／入り直しが要らない／th の版が合っている |
| `meas.reroute` | 上と同じ（走っている間に出すので、下端の条件も同じに見る） |
| `meas.stop`・`meas.abort`・`meas.finish` | **いつでも通す**（止める側の指示は塞がない） |
| **表に無い指示** | **出さない。**`meas.turn`・`meas.translate`・`meas.set_limits`・`meas.done` など測定機構の側やお立会試験で使う指示の条件は、その詳細設計でこの表に足す |
| 昇降機を下げる | 腕が格納位置にある（測定機構なしを除く）／ss の依頼が終わっている（**ss の状態が `IDLE`。本システム以外の依頼も含む**）／腕の制御器と通信できる（測定機構があるとき。[Spec-arm.md](../spec/Spec-arm.md)「通信できなくなったら昇降機も動かさない」） |
| ss への依頼 | th が `WAIT`／昇降機と腕の状態が読める／腕が格納位置にある |

### 4.2 走っている間の見張り（`drive_watch(snapshot)`）

th の状態が `NAV`・`ALIGN`・`BLOCKED` の間、`/measure/status` を受けるたびと昇降機の様子が変わるたびに呼ぶ。

| 見るもの | 振る舞い |
| --- | --- |
| 昇降機が下端から `lift_drift_stop_mm` 以上離れた | `meas.stop` |
| 昇降機の高さか腕の状態が読めなくなった（`lift_state_stale_ms` 届かない） | `meas.stop` |

**`ADJUST`（盤前の旋回）は高さで止める対象から外す**（[Spec-auto.md](../spec/Spec-auto.md) §4）。
**th の状態が古くても、最後に読めた状態で見張る**（2026-11-11 WP-AUTO-02 の受け入れ検査で決めた。th の状態の通り道が不調でも生存確認は出続け、th は走り続けうるため。一度も読めていなければ見ない）。
