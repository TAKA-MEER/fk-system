# Spec-arm — 測定機構の制御の分担

[Spec.md](Spec.md) §1.3 の詳細。**実装（ノード名・ピン・アルゴリズム）は書かない。**

## 1. 制御の分担

**測定機構の制御の分担**（2026-11-01 ユーザー決定。いまの仮の構成 [arm.md](../arm.md) による。制御器はいまはどちらも ESP32。`FD-6` のとおり機器名には依存しない）:

| 制御器 | 受け持つもの |
| --- | --- |
| **アームの制御器**（腕の根元に置く。測定機構の一部。**カメラモジュールと同様に無線と電池**にし、昇降機と一緒に上下する線を持たない。2026-11-02 ユーザー決定） | 腕を伸ばす・先端の上下・腕が格納位置か展開位置かの検知（スイッチ）・**腕の角度の検知**（2026-11-02 ユーザー決定）。**測定の間は、ドラムと昇降機を主導して動かす**。**腕が格納位置にないかを昇降部へ知らせる**（「腕が出ています」の表示のため。2026-11-02 ユーザー決定。hve-system の要求を承認） |
| **昇降機の制御器**（hve-system の昇降部） | 昇降機と、**腕を起こすドラム**。ドラムは機体側にあり、昇降機が動くと線の長さが変わるので、**昇降機に合わせて動かす**。昇降部が合わせるので、本システム・ss-system・人のどれが昇降機を動かしても、ドラムはついていく。**天井の距離・上限・下限は、昇降機の制御器が命令を拒否して守る**（アームの制御器からの命令も同じ） |

- **腕を起こすときと格納するときは、盤に対して 90° 旋回した向きで行う**（盤に向いたまま起こす・下ろすと、腕が盤に当たる。2026-11-04 ユーザー決定。測定機構の変更で分かった）。起こすときは「90° 旋回 → 腕を起こす → 腕を十分に上げる → 90° 戻して向きを合わせる」、格納するときは「腕を十分に上げる → 90° 旋回 → 格納」の順。旋回は本システムが th-system に指示する（お立会試験でも。[Spec.md](Spec.md) §1.1.1）。**左右は、腕が振れる範囲が空いている側を本システムが選ぶ。両側とも塞がっていれば測らずに止める**（2026-11-04 ユーザー決定。th-system の旋回の前の確認は機体の角が描く円の中だけで、腕が振れる範囲は見ていない。確かめ方は `FK-X7`）。
- **測るときは、必要な情報をアームの制御器に渡し、測定完了まで任せる**（本システムがクローラで向きを合わせてから渡す。お立会試験も同じ。2026-11-04 ユーザー決定。それまでお立会試験では向きを合わせなかった。[Spec.md](Spec.md) §1.1.1）。腕を起こしたあとに本システムの旋回が入るので、**任せるのは向きを合わせたあと（腕を伸ばすところ）から。腕を起こすのは本システムが別に指示する**（2026-11-04 の決定から導いた。指示をアームの制御器へ出すのは格納に合わせたもので、ユーザーの確認待ち）。アームの制御器が主導してドラムと昇降機を動かす。**任せるのは、当てて値を保存し、先端を上げ、腕の伸びを戻すまで。腕の格納は本システムが別に指示する**（2026-11-02 ユーザー決定）。**格納の指示はアームの制御器へ出し、格納のドラムはアームの制御器が昇降部に命じる**（2026-11-02 ユーザー決定。hve `H-M7` の問いへの答え）。
- **腕が格納位置にない間は、本システムは th-system に動く指示を出さず、ss-system にも依頼しない。ただし、先端を上げて伸びを戻していれば、腕を起こしたまま盤前で旋回してよい。腕を起こしたまま並進はしない（並進は腕を格納してから）**（2026-11-02 ユーザー決定。`FK-X5`）。th-system が動き出す前に確かめるのは機体の角が描く円の中だけで、天面より上に出た腕は見ていない。**そこで旋回の前に毎回、本システムが昇降機で腕を十分に上げ、旋回の間に腕を何にも当てないようにする。十分に上げられない（昇降部が上昇を拒む）ときは旋回しない。格納も 90° 旋回してからなので、盤に向いたままでは格納もできず、止めて人が判断する**（盤に対して 90° 旋回した向きにいれば、その場で格納できる）（2026-11-02 ユーザー決定。2026-11-04 に「格納してから旋回する」を、格納にも旋回が要ると分かったので改めた。昇降機の操作は下の箇条のとおり昇降機の制御器へ直接送る。どれだけ上げれば十分かは `FK-X7`）。
- **それ以外の昇降機の操作は、本システムから昇降機の制御器へ直接送る**（移動の前に下げる `FD-14` など）。
- **原点取り**（昇降部は電源を入れ直すと、一度下端まで下げるまで上昇しない。hve-system [Spec-safety.md](../../../../hve-system/docs/plan/spec/Spec-safety.md) §1.2）: **腕が格納位置にないときは、原点取りの下降をしない。腕を格納してから下げる。**昇降機を上げられず格納もできない（腕が天面の上に出ているなど。格納には 90° 旋回が要り、旋回には腕を十分に上げる必要がある。2026-11-04）ときは、通信できないときと同じく人が判断する（2026-11-02 ユーザー決定。測定中に電源が切れると、ドラムはその場で保つので腕は起きた・伸びたまま残り、そのまま下げると腕が天面に降りるため）。hve-system は、高さが読めない間にアームの制御器が腕が格納位置にないと知らせていれば、昇降部とカメラモジュールの画面に警告を出し、下降は拒否しない（人が下げるときは警告を見て人が守る。hve-system [Spec-safety.md](../../../../hve-system/docs/plan/spec/Spec-safety.md) §1.2。2026-11-02 hve のユーザー決定）。
- **測定機構が付いているか、昇降機の制御器の基板に測定機構のコネクタがつながったことを検知する仕組みをつける。**付いているときは、アームの制御器と昇降機の制御器が通信する。**検知しているのに通信できないときは、昇降機を動かさない。下げることもしない。点検用の物理ボタン（hve-system [Spec-ui.md](../../../../hve-system/docs/plan/spec/Spec-ui.md) §0.3）でも動かさない。**基本は異常を解消して通信を戻してから下ろす。直せないときは、**人がアームの安全を判断し、コネクタを抜くかも人が決める**（ソフトウェアが関わるのは確認ダイアログだけ）（2026-11-01 ユーザー決定）。
- **昇降機の制御器の起動中に、コネクタの状態が変わったら、確認ダイアログを出す。出すのは昇降機の制御器を直接操作する画面**（hve-system の昇降部の画面。hve-system [Spec-ui.md](../../../../hve-system/docs/plan/spec/Spec-ui.md) §0.2。2026-11-01 ユーザー決定）。確かめること（2026-11-02 ユーザー決定。hve `H-U10`。同日に hve-system のユーザーが変えた形にそろえた）:

  | コネクタ | 確かめること | 答えたあと |
  | --- | --- | --- |
  | **抜けた** | **意図的に取り外したか** | 取り外した → 測定機構が付いていないときと同じに戻し、昇降機を動かせる（ドラムは動かさない） |
  | **つながった** | **意図的に取り付けたか** | 取り付けた → アームの制御器と通信できてから動かせる |

  **断線・接触不良などの故障のときは答えない。コネクタが変わる前の状態に戻る（直る）まで確認ダイアログを出し続け、その間は昇降機を動かさない。**戻ればダイアログは閉じ、確認なしでまた動かせる（接触不良がくり返すと、止まる・動けるをくり返す。その間のドラムのずれは、下の「ドラムが遅れたら止める」で止める）。直せずに取り外すと人が決めたときは、そのダイアログで「取り外した」と答える（2026-11-02 hve のユーザーが変えたものを、ユーザーが承認。「断線」と答えたあと止めたままを解く入口が無いため）。
- **昇降機が引っかかったとき**（ロープだけ繰り出され、高さの表示だけ下がる。hve-system [Spec-safety.md](../../../../hve-system/docs/plan/spec/Spec-safety.md) §1.2）は、**アームの格納位置・展開位置の検知が、ドラムの制御に要る情報を与える。**
- **腕の角度を測り、格納位置・展開位置の検知とあわせて、ドラムのフィードバックにする。腕はストッパーに当たらない位置に保つ**（2026-11-02 ユーザー決定。ストッパーに当たったまま線が張り続けると腕や線を傷めるため。角度が分かるので、線が張る側も緩む側も分かる）。角度をどう昇降部へ渡すかは、制御器どうしの取り決めの中身（hve-system `H-M7`）。ドラムに回転の検知を足すことは検討中（2026-11-02）。
- **ドラムが昇降機に合わせて動けない（遅れる・回らない）ときは、昇降機を止める**（2026-11-02 ユーザー決定。hve-system の提案を採った）。hve-system は、止めたあと**ずれが戻るまで上昇も下降もしない**（点検用の物理ボタンも同じ）ことにした。ドラムが追いついて腕の角度が戻れば、また動かせる。ドラムが壊れていれば、通信できないときと同じく人が判断する（hve-system [Spec-safety.md](../../../../hve-system/docs/plan/spec/Spec-safety.md) §2 #4g。2026-11-02 hve のユーザー決定）。
- **昇降機の制御器の基板のコネクタは、ドラムをつなぐ**（2026-11-02 ユーザー決定）。**コネクタを抜いたあとは、ドラムを動かさない**（2026-11-02 ユーザー決定。腕の安全は人が守る）。
- **ドラムは、電源が切れてもその場で保つ**（腕が落ちないように。2026-11-02 ユーザー決定。hve-system の要求を承認）。
- **測定中に人が昇降機を操作すると、最後の操作が勝つのでアームの制御器は取って代わられる。アームの制御器はそれを知って止まる**（2026-11-02 ユーザー決定。hve-system の要求を承認）。**本システム（アームの制御器を含む）が操作している間は、昇降機を操作する画面に「測定操作中」などと出す。人の操作は拒否しない（腕が伸びていることに気づかずに人が昇降機を動かして当ててしまうのを防ぎつつ、人の邪魔をしないため）**（2026-11-02 ユーザー決定）。hve-system は、昇降部の画面とカメラモジュールの画面の両方に出し、腕が格納位置にない間は「腕が出ています」も出すことにした（hve-system [Spec-ui.md](../../../../hve-system/docs/plan/spec/Spec-ui.md) §1.6。2026-11-02 hve のユーザー決定）。
- **非常停止**: 本システムの非常停止を、無線でアームの制御器へ送る。さらなる非常停止の仕組みは検討中（2026-11-02 ユーザー決定）。
- **書く担当**: ドラムの制御（昇降機の制御器のファーム）と、2 つの制御器のあいだの通信の取り決めは hve-system が書き、本システムが確かめる。アームの制御器のファームは本システムが書く（2026-11-02 ユーザー決定。hve-system の要求を承認）。
