## 1. 対象

**配電盤上部を確認するロボットに、測定機能を加えるソフトウェア**（2026-10-30 ユーザー決定）。
走行系・昇降機・カメラを組み合わせて使い、**自動での測定を目指す。**
そのために、**各システムへの指示と、各システムからの情報の取得**を本システムが行う。
**画像認識は別システム（ss-system）に任せ、本システムはそこへ欲しい情報を渡す。その情報を得るために hve-system のカメラを動かすのは ss-system**（2026-10-31 ユーザー決定。`FD-9`・`FD-10`）。

| 担当 | 範囲 | 出典 |
| --- | --- | --- |
| **本システム** | 測定（膜厚・板厚。§1.3）。走行系・hve-system への指示と情報の取得（**カメラを動かすのは ss-system。昇降機は本システムと ss-system の両方が動かす**。`FD-11`）。**走行の指示は本システムが出す**。2 つの測定モード（§1.1） | 2026-10-30 ユーザー決定 |
| th-system | 配電盤上部を確認するロボットのうち、移動に関わるすべて（WebUI・始業点検・校正・異常時の扱いを含む） | th-system [Spec.md](../../../../th-system/docs/plan/spec/Spec.md) §1 |
| hve-system | th-system の走行部に載る昇降機と上部カメラ | hve-system [Spec.md](../../../../hve-system/docs/plan/spec/Spec.md) §1 |
| **ss-system** | **画像認識。**本システムから**方向の範囲**を受け取り、**それを得るために hve-system のカメラと昇降機を動かして**、**その範囲の盤の位置**（ローカル座標系）を返す（2026-11-01 ユーザー決定。測る点は本システムが決める）。**仕様は本システムの設計が決める**（ss-system は、将来作るかもしれない th-system の前日準備の自動化にも対応できる汎用性を意識する）。**別リポジトリ `../ss-system`**（ss-system [Spec.md](../../../../ss-system/docs/plan/spec/Spec.md)） | 2026-10-31 ユーザー決定 |

**指示の権限**（2026-10-30 ユーザー決定）: **走行の指示は本システムが出す。hve-system は走行を指示する権限を持たない。**
走行と昇降・カメラを組み合わせる判断は本システムが持ち、hve-system は th-system と直接やり取りしない（hve-system `HD-1` はそのまま）。
**走行系への指示と返る状態は th-system [Spec-measure.md](../../../../th-system/docs/plan/spec/Spec-measure.md) §3 のとおり**（2026-11-04 ユーザー決定。具体的な取り決めは th-system が書き、本システムが確かめる）。昇降機・画像認識に何を指示し何を取るかの残りは未定（[Spec-open.md](Spec-open.md) `FK-A1`）。

**カメラの操作**（2026-10-31 ユーザー決定。`FD-10`）: **本システムは ss-system に欲しい情報を渡すだけで、その情報を得るために hve-system のカメラを動かすのは ss-system。**
**ss-system の仕様は本システムの設計が決める。ただし ss-system は本システム専用にせず、汎用的になるよう意識する**（将来作るかもしれない、th-system の前日準備（th-system [Spec-onsite.md](../../../../th-system/docs/plan/spec/Spec-onsite.md) §2）を自動化するシステムにも対応できるように）。

**昇降機の操作**（2026-10-31 ユーザー決定。`FD-11`）: **本システムと ss-system の両方が昇降機を動かす権限を持つ。**ss-system は**カメラの位置合わせ**に、本システムは**測定機構を動かす**のに使う。
**ss-system が昇降機を動かしている間、本システムは昇降機を動かさない。これに気をつけるのは指示を出す本システムで、ss-system には気にする義務はない。**

### 1.1 測定モード

**2 つ作る**（2026-10-30 ユーザー決定）。中身は 2026-10-31 ユーザー決定。

| 項目 | **お立会試験中の測定** | **自律測定** |
| --- | --- | --- |
| 何か | お立会試験（先方が立ち会う試験）の最中に測定する | ロボットが自律で測定する |
| 使う場面 | **走行系の盤前移動で盤前に到着したとき**（盤前までは走行系が運ぶ。th-system [Spec-onsite.md](../../../../th-system/docs/plan/spec/Spec-onsite.md)） | 盤の前に居なくてもよい。**お立会試験以外でも使う応用的・挑戦的な機能**（2026-11-01 ユーザー決定。`FD-13`） |
| 準備 | 走行系の前日準備（試験場内地図・盤のピン）を使う | **要らない。**起動のたびに地図を作り直す（§1.1.2） |
| 測る盤 | 目の前の盤 | **盤の配置図から使用者が選ぶ。複数選べる** |
| 盤までの移動 | 走行系の盤前移動（本システムは走らせない。**盤前で腕を起こす・格納するための旋回だけは本システムが指示する**。§1.1.1。2026-11-04 ユーザー決定） | **選ばれた盤へ自律で移動する**（§1.1.2） |
| 測る点 | **天面の中央 1 点** | **天面の四隅と中央の 5 点** |
| 人の操作 | **「測定」ボタンを押すだけ** | th-system のメインメニューの「自律測定」から入って「許可する」を押し（§1.2）、**盤を選ぶだけ**（以降は自動） |

#### 1.1.1 お立会試験中の測定の流れ（盤前到着後。自律測定の盤前到着後もほぼ同じ）

| 順 | 何をするか | 担当 |
| --- | --- | --- |
| 1 | **「測定」ボタンを押すと始まる。**本システムが ss-system に、盤の位置を探す**方向の範囲**を渡す（2026-11-01 ユーザー決定） | 本システム |
| 2 | 昇降機を動かし、カメラに天面が映るまで走査する | **ss-system**（hve-system のカメラと昇降機を動かす。`FD-10`・`FD-11`） |
| 3 | 天面を見つけたら、**画像認識に最適な画角に調整する** | **ss-system** |
| 4 | **その範囲の盤の位置を画像から推定し、本システムへ返す**（ローカル座標系。LiDAR の地図は考慮しない。2026-11-01 ユーザー決定）。終わったら後片付けとして**昇降機を元の高さに戻す** | **ss-system** |
| 5 | 返った盤の位置から**測る点（天面中央）を決め、画面に表示する。人の判断は待たない**（2026-11-01 ユーザー決定） | 本システム |
| 6 | **測定機構を動かして測る**（§1.3・[Spec-arm.md](Spec-arm.md)。大まかな上下は昇降機、前後と最後の上下は測定機構）。**盤に向いたまま腕を起こすと盤に当たるので、盤に対して 90° 旋回してから腕を起こし、腕を十分に上げてから 90° 戻して天面の中央へ向きを合わせる**（2026-11-04 ユーザー決定。測定機構の変更で分かった。旋回は本システムが th-system に指示する。向きは ss-system が返した盤の位置から決める。左右は腕が振れる範囲が空いている側（本システムが範囲を渡し、th-system が LiDAR で確かめる。2026-11-04 ユーザー決定）を本システムが選び、両側とも塞がっていれば測らずに止める。自律測定ではその盤を飛ばす（[Spec-auto.md](Spec-auto.md) §6））。そのうえで**測定開始の指示と測定点までの水平距離（腕を伸ばす量に使う）をアームの制御器に渡し、測定完了（伸びを戻すまで）まで任せる**（渡すものは 2026-11-04 ユーザー決定）（お立会試験で向きを合わせないとした 2026-11-01 の決定は、旋回が毎回要るようになったのでやめた） | 本システム（アームの制御器） |
| 7 | **測り終えたら、腕を十分に上げてから 90° 旋回して腕の格納を指示し**（盤に向いたまま格納しても盤に当たる。2026-11-04 ユーザー決定）、**腕が格納位置になったら着いたときの向きへ戻し、昇降機を測定を始める前の高さへ戻してから、th-system へ「測定を終えた」を返す**（高さを戻すのは 2026-11-04 ユーザー決定。測定のために上げた分を、停止命令が解けたあとに残さないように。向きを戻すのは 2026-11-04 ユーザー決定。人の「カメラ」での撮影や次の盤前移動が、着いたときと同じ向きから始まるように。自律測定は次の点・次の盤へ動くので戻さない。「測定を終えた」は th-system の停止命令を解く合図。2026-11-01 th-system の要求をユーザーが承認。格納してから返すのは 2026-11-02 ユーザー決定。停止命令が解けると人が機体を動かせるため） | 本システム |

お立会試験中の測定の決まり（2026-11-01 ユーザー決定）:

| 場面 | 振る舞い |
| --- | --- |
| **天面が見つからなかった** | **「中止する」か「人がカメラを動かして天面が映る位置にする」かを選ぶボタンを出す** |
| **連盤が映っている** | **正面の盤を測る** |
| **盤前で旋回する**（2026-11-04 ユーザー決定） | **「測定機能へ」の停止命令の間でも、本システムからのその場旋回だけは th-system が受け付ける**（旋回の前の確認つき。行き先・並進・ジョグは拒否のまま。th-system への申し送り。[Spec-open.md](Spec-open.md) §1.2）。**盤のピン（th-system の前日準備）は、到着の誤差（th-system の到着の許容差 ±0.12 m）があっても盤面が機体の中心から 0.389 m 以上離れるように、余裕をとって登録する**（それより近いと旋回の前の確認で回れない。余裕の値は [Spec-open.md](Spec-open.md) `FK-V1`）。**旋回は完了を受けてから次の指示を出し、旋回中は「測定を終えた」を送らない**（th-system の依頼を承認。2026-11-04）。**旋回が途中で止まったら**（回復フォルト・通信途絶・非常停止。th-system は回り直さない）、**th-system が返す今の向き（自己位置）から残りの角度を出し直す**（2026-11-04 ユーザー決定。th-system への申し送り） |

#### 1.1.2 自律測定の流れ

| 順 | 何をするか |
| --- | --- |
| 1 | **起動直後に、周囲の配電盤の配置を地図（配置図）にまとめる。**前日の地図に関係なく、**起動のたびに作り直す**（`FD-13`）。本システムが ss-system に方向の範囲を渡して盤の位置を求め、ss-system がカメラを上げて撮る（`FD-10`・`FD-11`） |
| 2 | **使用者が配置図から測る盤を選ぶ**（複数可）。**複数のときは、盤の正面に向かって右から順に回る**（正面の決め方・列が複数あるときは [Spec-auto.md](Spec-auto.md) §2） |
| 3 | **移動の前に、本システムが昇降機を下げる**（例外は下表。ss-system は終わったら元の高さに戻すが、**本システムはそれを当てにせず、下げる必要があれば自分で下げる**。`FD-14`）。そのうえで **LiDAR で地図を作りながら（SLAM）目的の盤へ移動する**（この地図も起動のたびに作り直す。`FD-13`）。まだ地図ができていない所も推測で経路を引いて動き出す。進むにつれ地図が正確になり、経路の修正が要れば**経路を再計算する** |
| 4 | 盤前に到着したら、§1.1.1 とほぼ同じ流れで**四隅と中央の 5 点を測る**（推定した点は画面に表示するが、人の判断は待たない）。お立会試験との違いは、**点ごとにクローラで向きを変えること**（測定機構は左右に動かせないので、左右の位置合わせは**クローラのその場旋回**で行う）。**旋回は本システムが th-system に角度を指示する**（下表）。**点と点のあいだは、先端を上げて伸びを戻していれば、腕を起こしたまま旋回してよい**（2026-11-02 ユーザー決定。[Spec-arm.md](Spec-arm.md)）。**旋回の前に毎回、腕を十分に上げて、旋回の間に腕が当たらないようにする**（腕は昇降機と一緒に上下するので、昇降機で上げる。**腕を起こしたまま並進はしない**。2026-11-02 ユーザー決定。上げられなければ旋回しない。**格納も 90° 旋回してからなので、盤に向いたままでは格納もできず、止めて人が判断する**。2026-11-04。**十分とは、腕が盤の高さ 2350 mm に天面の排気口 150 mm と余裕を足した高さより上に出ること**（2026-11-04 ユーザー決定。余裕の値は [Spec-open.md](Spec-open.md) `FK-X7`））。腕を起こすとき・格納するときの 90° 旋回は §1.1.1 と同じ |

**カメラを下げずに動いてよい移動**（2026-10-31 ユーザー決定）: **点と点のあいだ・連盤の盤から盤への移動で、移動の長さが一定以下のとき。**その長さは未定（[Spec-open.md](Spec-open.md) `FK-V5`）。それより長い移動は下げてから動く。**当面は 0 とし、毎回下げる**（暫定。2026-11-04。1 盤につき立ち位置を 1 か所にしたので、点と点のあいだは旋回だけになる。[Spec-auto.md](Spec-auto.md) §1・§4）。
**th-system は昇降機の高さを知らないので、本システムが速度と加速度の上限を指定する**（2026-11-01 ユーザー決定）。
**昇降機の高さが一定以上のとき、また昇降量が大きく変わったとき（走行の揺れで多少は動くため、大きく変わったときだけ）は止める**（2026-11-01 ユーザー決定。`FK-X1`。値は `FK-V5`。止め方と暫定の閾値は [Spec-auto.md](Spec-auto.md) §4）。**ただし、盤前のその場旋回と低速並進は、高さで止める対象から外す**（2026-11-01 ユーザー決定。測るには昇降機を天面より上に上げるため）。

**移動の役割分担**（2026-10-31 ユーザー決定。`FD-2` の中身。盤前の動きは 2026-11-01 ユーザー決定）:

| 担当 | 受け持つこと |
| --- | --- |
| **本システム** | **目的地の設定・経路再計算・中止・終了の指示**（中止は、今の目的地・指示を捨てて止まって待たせる。終了は、人が本システムの画面で抜ける操作をしたとき th-system をメインメニューへ戻す。2026-11-01 th-system の要求をユーザーが承認）。**盤前の停止位置は、盤面が機体の中心から 0.389 m 以上（機体の前面から約 0.11 m 以上）離れるように決める**（それより近いと th-system の動き出す前の確認に盤が入り、旋回も発進もできなくなる。2026-11-01 th-system の要求をユーザーが承認）。盤前では**その場旋回の角度**、**低速並進の左右と距離**、昇降機を上げたまま動くときの**速度と加速度の上限**を指示する |
| th-system | **経路の計画・走行制御・停止。**盤前の旋回と並進（クローラは横に動けないので、旋回と走行の組み合わせ）も th-system が制御する |

**本システムは th-system に対して人と同等の権限を持つ**（2026-11-01 ユーザー決定。`FD-12`）。
本システムの指示（目的地・経路再計算・発進）は、th-system では試験員の操作と同じに扱う。
**明示操作**は、th-system の「自律動作を許可しますか」で**「許可する」を押すこと**（th-system への明示操作。§1.2）と、**盤の選択**（本システムへの明示操作）。
**発進前の周りの確認は th-system が担う。人の手動操作が割り込んだら一時停止し、「走行」が押されるのを待つ。停止と走行の関係は th-system と同じにする**（2026-11-01 ユーザー決定）。

**位置合わせの精度**（2026-11-01 ユーザー決定）: 旋回の角度の精度は、**不感帯を測ることで改善を見込む。**
旋回・並進で必要な精度が得られなかった場合は、**画像認識によるフィードバック修正**の導入を検討する。要る精度は未定（[Spec-open.md](Spec-open.md) `FK-V4`）。

**自律測定は、th-system の試験場内の動作（前日準備・盤前移動）とはほとんど別物になる**（2026-11-01 ユーザー決定。`FD-13`）。
ノウハウは活かすが、**準備なしで、地図を自動で作りながら作業をこなせるようにする。**

**配置図と地図**（2026-11-01 ユーザー決定）:

| 項目 | 決まっていること |
| --- | --- |
| 表示 | **配置図と（LiDAR の）地図を重ねて出す** |
| 自己位置推定 | **配置図は使わない** |
| 配置図の精度が足りないとき | 地図との統合を考える |
| 移動中 | **カメラが揺れるので、画像認識はできない前提にする** |
| 配置図の精度を上げる | **定期的に一時停止して画像認識をやり直す**ことを考えている |
| 推測で引いた経路の先に障害物があったとき | **th-system が止める** |

**画像からの推定と、そのためのカメラの操作は ss-system が行い、本システムは欲しい情報を渡して結果を受け取る**（`FD-9`・`FD-10`）。
**ss-system は、本システムが指示した方向の範囲にある盤の位置を返す**（ローカル座標系。LiDAR の地図は考慮しない。2026-11-01 ユーザー決定）。測る点は、返った盤の位置から本システムが決める。
**天面の位置の推定は、天板四隅の吊り金具を手がかりにする方法を検証済み**（合成データでの検証。実物では未確認）。
方法と精度は検証レポート「[吊り金具による配電盤配置推定 検証レポート](https://claude.ai/artifact/A3Pz8dbXUn2srTn8NQFq2J)」（spec ではない。写さずにリンクする）。
自律測定は**これまでの技術**（走行系の自律走行・この推定）を応用する。
未定の残りは [Spec-open.md](Spec-open.md) `FK-S3`・`FK-S5`・`FK-V4`。

**移動の決まり**（測定機構との境目・配置図・ss-system への依頼・走行と昇降の排他・一時停止からの再開・測れないとき・画面の操作）は [Spec-auto.md](Spec-auto.md)（2026-11-04 ユーザー決定）。

### 1.2 画面の入口

**走行系（th-system）の画面を主とし、そこからカメラの画面と本システムの画面へ移れるようにする**
（2026-10-30 ユーザー決定。**本システムだけでなく全体に関わる判断**）。
th-system・hve-system 側の画面と仕様の変更が要る（[Spec-open.md](Spec-open.md) §1）。

**自律測定は、th-system のメインメニューの「自律測定」ボタンから入る。**押すと「自律動作を許可しますか」と出て、**「許可する」を押したことが th-system への明示操作**になり、th-system は本システムからの指示を受けるモードに入る（2026-11-01 ユーザー決定。th-system 側の決定に合わせた。th-system [Spec-measure.md](../../../../th-system/docs/plan/spec/Spec-measure.md) §1。`FD-12`）。**許可しただけでは動き出さない。**
モード中の th-system の画面の「測定機能の画面へ」は、画面を移るだけ。
**お立会試験中の測定の入口は、th-system にいま仮で置いている「作業中」ボタンを置き換えて作る**（2026-11-01 ユーザー決定）。th-system では盤前の「作業中」を「**測定機能へ**」と「**カメラ**」（カメラ機能へのリンク）に置き換えた（th `F-48`。th-system [Spec-onsite.md](../../../../th-system/docs/plan/spec/Spec-onsite.md) §7.2）。**「測定機能へ」が th-system の停止命令を兼ね、本システムの「測定を終えた」（§1.1.1）で解ける。**本システムが落ちたときは、人が th-system の試験画面の「停止を解く」で解ける（「**測定機構の腕が格納位置にあることを確かめましたか**」の確認つき。th `5937631`）。**「測定を終えた」は腕を格納してから返す**（§1.1.1。伸びを戻しただけの、腕が起きた状態では返さない）。

本システムの画面（2026-11-01 ユーザー決定）:

| 項目 | 決まっていること |
| --- | --- |
| 置き場所 | **th-system とは別のポート** |
| 操作性 | **あたかも th-system の中にいるような、近い操作性にする** |
| 抜け方 | **th-system のほかの画面と同じく、いつでも抜けられる。**測り終えても自動では抜けず、**人の操作で抜ける。抜ける先は th-system のメインメニュー**（2026-11-01 ユーザー決定）。**人が抜ける操作をしたら、th-system へ「終了」の指示を送る**（2026-11-01 th-system の要求をユーザーが承認） |
| **ヘッダー** | **th-system と同じヘッダーを置く**（th-system のヘッダーには、非常停止と、異常を知らせる枠がある。2026-11-01 ユーザー決定）。**ヘッダーの非常停止は th-system の画面の非常停止と同じ扱い**（送り続け、押した側でラッチする。th-system [Spec-safety.md](../../../../th-system/docs/plan/spec/Spec-safety.md) §4.2。2026-11-01 th-system の要求をユーザーが承認）。th-system の異常ウィンドウへの応答は、ヘッダーから人が押す。本システムが自分の判断で応答しない（th-system の決まり。th `F-49`） |

| 本システムの起動中の th-system の画面 | 基本は表示されないが、**非常停止等のヘッダー・本システムへ移るボタン・本システムの終了ボタン**を置く |

| **在席の申告** | **本システムの画面から th-system へ、在席と画面（ゾーン `IN`）の申告を送る。**th-system は WebUI が前面にある端末が 1 台も無いと止まり、自律測定の間は本システムの画面も「使用中」に数える（2026-11-01 th-system の要求をユーザーが承認。**お立会試験の停止命令の間も同じく申告する**（申告が無いと停止命令の間の旋回が動かない。2026-11-04 th-system の要求をユーザーが承認）。th-system [Spec-measure.md](../../../../th-system/docs/plan/spec/Spec-measure.md) §6） |


### 1.3 測るもの

**膜厚測定と板厚測定の 2 つ。どちらも同じ操作でできるようにする**（2026-10-30 ユーザー決定）。

| 項目 | 決まっていること | 出典 |
| --- | --- | --- |
| 測り方 | **測定器を測る面に垂直に押し当てて測る** | 2026-10-30 ユーザー決定 |
| 最初に測る面 | **天面から目指す**（ほかの面は後） | 同上 |
| 測定器 | **高価で購入できないので、モックアップで再現する** | 同上 |
| モックアップが再現するもの | **概形と、接触の検知**の 2 つだけ | 同上 |
| モックアップでの測定値 | **値は扱わない。**測り終えたら「**値を保存しました**」と示して済ませる | 同上 |
| **測定機構でできること** | **昇降機に取り付き、昇降機と一緒に上下する。測定器を前後に動かせる。左右には動かせない**（左右はクローラのその場旋回で合わせる。§1.1.2） | 2026-10-31 ユーザー決定 |

測る点の数は §1.1（お立会試験は中央 1 点、自律は四隅と中央の 5 点）。「四隅」を縁からどれだけ内側にとるか・精度・本物の測定器での結果の残し方は未定（[Spec-open.md](Spec-open.md) `FK-S2`・`FK-V1`）。
測定機構の**設計は未定で、構成機器は変わりうる**（案は [arm.md](../arm.md)。spec ではない）。**できること（上の表）は決まった**（2026-10-31）。
**天面へ押し当てる最後の動き（最終アプローチ）の機構は検討中**（2026-11-01。昇降機は自重で下がるので、昇降機を下げて押し当てるとたるむ。[Spec-open.md](Spec-open.md) `FK-A5`）。いまの仮の構成では、腕の先端の上下で当てる（[arm.md](../arm.md)）。

**測定機構の制御の分担**（2 つの制御器の受け持ち・測るときに任せる範囲・腕が出ている間の決まり・原点取り・通信できないときと確認ダイアログ・ドラム・非常停止・書く担当）は [Spec-arm.md](Spec-arm.md)。

### 1.4 製品への接触

**製品に触れるのは本システムの測定器だけ**（2026-10-30 ユーザー決定）。

| 項目 | 決まっていること |
| --- | --- |
| 接触を行うのは | **本システム。**th-system の走行系は製品に接触しない（th-system の G1「物への接触 0 件」は走行系についてそのまま成り立つ） |
| 接触してよいもの | **測定器だけ。**腕・機体・昇降機など、測定器以外は製品に接触させない |

**接触は、上下する先端に付けたスイッチで検知する**（2026-11-04 ユーザー決定。モックアップでも同じ）。押し当ての力の上限と、測定器以外が当たらないことをどう保証するかは未定（[Spec-open.md](Spec-open.md) `FK-X4`・`FK-V3`）。

| **`FD-1`** | **画面の主は走行系の画面。**カメラ・測定機能へはそこから移る | 2026-10-30 ユーザー決定（§1.2） |
| **`FD-2`** | **走行の指示は本システムが出す。hve-system は走行を指示する権限を持たない。**本システムが出すのは**目的地と経路再計算の指示**で、経路の計画・走行制御・停止は th-system が持つ | 2026-10-30 ユーザー決定（§1）／ 中身は 2026-10-31（§1.1.2） |
| **`FD-3`** | **膜厚測定と板厚測定は同じ操作でできる** | 2026-10-30 ユーザー決定（§1.3） |
| **`FD-4`** | **測定器は垂直に押し当てて測る。まず天面から** | 2026-10-30 ユーザー決定（§1.3） |
| **`FD-5`** | **製品に触れるのは本システムの測定器だけ。**走行系も、測定器以外の部分も製品に接触させない | 2026-10-30 ユーザー決定（§1.4） |
| **`FD-6`** | **測定機構の構成機器は変わりうる。**spec は機器名に依存しない書き方をし、機器を替えても仕様が変わらないようにする | 2026-10-30 ユーザー（機構は開発中） |
| **`FD-7`** | **測る点は画像から推定する。**お立会試験中の測定は「測定」ボタン 1 つで中央 1 点、自律測定は盤を選ぶだけで四隅と中央の 5 点 | 2026-10-31 ユーザー決定（§1.1） |
| **`FD-8`** | **本システムは、人の代わりに操作の判断の一部を行うシステムである。**判断（どこへ行くか・経路を引き直すか・どこを測るか）は本システム、それを実行する制御（走行・停止）は各システムが持つ | 2026-10-31 ユーザー決定（§1.1.2） |
| **`FD-9`** | **画像認識は ss-system が担う。**本システムは ss-system に情報を要求し、返った推定結果を使って判断する | 2026-10-31 ユーザー決定（§1） |
| **`FD-10`** | **ss-system には欲しい情報を渡すだけにし、その情報を得るために hve-system のカメラを動かすのは ss-system。ss-system の仕様は本システムの設計が決めるが、ss-system は汎用的になるよう意識する**（本システム専用にしない） | 2026-10-31 ユーザー決定（§1） |
| **`FD-11`** | **昇降機は本システムと ss-system の両方が動かす。**ss-system はカメラの位置合わせに、本システムは測定機構を動かすのに使う。**ss-system の操作中に動かさないよう気をつけるのは本システム**（ss-system に義務はない） | 2026-10-31 ユーザー決定（§1） |
| **`FD-12`** | **本システムは th-system に対して人と同等の権限を持つ。**本システムの指示は th-system で試験員の操作と同じに扱う。明示操作は th-system の「自律動作を許可しますか」で「許可する」を押すこと（th-system へ）と盤の選択（本システムへ） | 2026-11-01 ユーザー決定（§1.1.2・§1.2） |
| **`FD-13`** | **自律測定はお立会試験以外でも使う応用的・挑戦的な機能。**準備なしで、起動のたびに地図を作り直し、地図を自動で作りながら作業をこなす。th-system の試験場内の動作とはほとんど別物 | 2026-11-01 ユーザー決定（§1.1・§1.1.2） |
| **`FD-14`** | **走行の前の安全は本システムが自分で確かめる。**移動の前に昇降機を下げるのは本システムで、ss-system の後片付け（元の高さに戻す）を当てにしない。昇降機の高さが一定以上のとき・昇降量が大きく変わったときは止める（高さの条件は、盤前のその場旋回と低速並進を除く） | 2026-11-01 ユーザー決定（§1.1.2） |

th-system の設計思想（SD-1〜SD-9）は**大まかに引き継ぐ**（目標というほど厳密にはしない。2026-11-01 ユーザー決定）。
