## 1. 対象

**配電盤上部を確認するロボットに、測定機能を加えるソフトウェア**（2026-10-30 ユーザー決定）。
走行系・昇降機・カメラを組み合わせて使い、**自動での測定を目指す。**
そのために、**各システムへの指示と、各システムからの情報の取得**を本システムが行う。
**画像認識は別システム（ss-system）に任せ、本システムはそこへ欲しい情報を渡す。その情報を得るために hve-system のカメラを動かすのは ss-system**（2026-10-31 ユーザー決定。`FD-9`・`FD-10`）。

| 担当 | 範囲 | 出典 |
| --- | --- | --- |
| **本システム** | 測定（膜厚・板厚。§1.3）。走行系・hve-system への指示と情報の取得（**カメラを動かすのは ss-system。昇降機は本システムと ss-system の両方が動かす**。`FD-11`）。**走行の指示は本システムが出す**。2 つの測定モード（§1.1） | 2026-10-30 ユーザー決定 |
| th-system | 配電盤上部を確認するロボットのうち、移動に関わるすべて（WebUI・始業点検・校正・異常時の扱いを含む） | th-system [Spec.md](../../../../th-system/docs/plan/spec/Spec.md) §1 |
| hve-system | th-system の走行部に載る昇降機と上部カメラ | hve-system [Spec.md](../../../../hve-system/docs/plan/spec/Spec.md) §1 |
| **ss-system** | **画像認識。**本システムから欲しい情報を受け取り、**それを得るために hve-system のカメラを動かして**、画像から推定した結果（盤の配置・天面の位置・天面中央までの距離など）を返す。**仕様は本システムの設計が決める**（ss-system は、将来作るかもしれない th-system の前日準備の自動化にも対応できる汎用性を意識する）。**別リポジトリ `../ss-system`**（ss-system [Spec.md](../../../../ss-system/docs/plan/spec/Spec.md)） | 2026-10-31 ユーザー決定 |

**指示の権限**（2026-10-30 ユーザー決定）: **走行の指示は本システムが出す。hve-system は走行を指示する権限を持たない。**
走行と昇降・カメラを組み合わせる判断は本システムが持ち、hve-system は th-system と直接やり取りしない（hve-system `HD-1` はそのまま）。
各システムに具体的に何を指示し何を取るかは未定（[Spec-open.md](Spec-open.md) `FK-A1`）。

**カメラの操作**（2026-10-31 ユーザー決定。`FD-10`）: **本システムは ss-system に欲しい情報を渡すだけで、その情報を得るために hve-system のカメラを動かすのは ss-system。**
**ss-system の仕様は本システムの設計が決める。ただし ss-system は本システム専用にせず、汎用的になるよう意識する**（将来作るかもしれない、th-system の前日準備（th-system [Spec-onsite.md](../../../../th-system/docs/plan/spec/Spec-onsite.md) §2）を自動化するシステムにも対応できるように）。

**昇降機の操作**（2026-10-31 ユーザー決定。`FD-11`）: **本システムと ss-system の両方が昇降機を動かす権限を持つ。**ss-system は**カメラの位置合わせ**に、本システムは**測定機構を動かす**のに使う。
**ss-system が昇降機を動かしている間、本システムは昇降機を動かさない。これに気をつけるのは指示を出す本システムで、ss-system には気にする義務はない。**

### 1.1 測定モード

**2 つ作る**（2026-10-30 ユーザー決定）。中身は 2026-10-31 ユーザー決定。

| 項目 | **立会試験中の測定** | **自律測定** |
| --- | --- | --- |
| 何か | お立会試験（先方が立ち会う試験）の最中に測定する | ロボットが自律で測定する |
| 使う場面 | **走行系の盤前移動で盤前に到着したとき**（盤前までは走行系が運ぶ。th-system [Spec-onsite.md](../../../../th-system/docs/plan/spec/Spec-onsite.md)） | 盤の前に居なくてもよい。**お立会試験以外でも使う応用的・挑戦的な機能**（2026-11-01 ユーザー決定。`FD-13`） |
| 準備 | 走行系の前日準備（試験場内地図・盤のピン）を使う | **要らない。**起動のたびに地図を作り直す（§1.1.2） |
| 測る盤 | 目の前の盤 | **盤の配置図から使用者が選ぶ。複数選べる** |
| 盤までの移動 | 走行系の盤前移動（本システムは走らせない） | **選ばれた盤へ自律で移動する**（§1.1.2） |
| 測る点 | **天面の中央 1 点** | **天面の四隅と中央の 5 点** |
| 人の操作 | **「測定」ボタンを押すだけ** | th-system のメインメニューの「自律測定」から入って「許可する」を押し（§1.2）、**盤を選ぶだけ**（以降は自動） |

#### 1.1.1 立会試験中の測定の流れ（盤前到着後。自律測定の盤前到着後もほぼ同じ）

| 順 | 何をするか | 担当 |
| --- | --- | --- |
| 1 | **「測定」ボタンを押すと始まる。**本システムが ss-system に欲しい情報（天面中央までの距離）を渡す | 本システム |
| 2 | 昇降機を動かし、カメラに天面が映るまで走査する | **ss-system**（hve-system のカメラと昇降機を動かす。`FD-10`・`FD-11`） |
| 3 | 天面を見つけたら、**画像認識に最適な画角に調整する** | **ss-system** |
| 4 | **天面中央までの距離を画像から推定し、本システムへ返す** | **ss-system** |
| 5 | **測定機構を動かして測る**（§1.3。上下は昇降機、前後は測定機構） | 本システム |

#### 1.1.2 自律測定の流れ

| 順 | 何をするか |
| --- | --- |
| 1 | **起動直後に、周囲の配電盤の配置を地図（配置図）にまとめる。**前日の地図に関係なく、**起動のたびに作り直す**（`FD-13`）。本システムが ss-system に配置図を求め、ss-system がカメラを上げて撮る（`FD-10`・`FD-11`） |
| 2 | **使用者が配置図から測る盤を選ぶ**（複数可）。**複数のときは、盤の正面に向かって右から順に回る** |
| 3 | **移動の前にカメラを下げる**（例外は下表）。そのうえで **LiDAR で地図を作りながら（SLAM）目的の盤へ移動する**（この地図も起動のたびに作り直す。`FD-13`）。まだ地図ができていない所も推測で経路を引いて動き出す。進むにつれ地図が正確になり、経路の修正が要れば**経路を再計算する** |
| 4 | 盤前に到着したら、§1.1.1 とほぼ同じ流れで**四隅と中央の 5 点を測る。**立会との違いは、**点ごとにクローラで向きを変えること**（測定機構は左右に動かせないので、左右の位置合わせは**クローラのその場旋回**で行う）。**旋回は本システムが th-system に角度を指示する**（下表） |

**カメラを下げずに動いてよい移動**（2026-10-31 ユーザー決定）: **点と点のあいだ・連盤の盤から盤への移動で、移動の長さが一定以下のとき。**その長さは未定（[Spec-open.md](Spec-open.md) `FK-V5`）。それより長い移動は下げてから動く。
**th-system は昇降機の高さを知らないので、本システムが速度と加速度の上限を指定する**（2026-11-01 ユーザー決定）。

**移動の役割分担**（2026-10-31 ユーザー決定。`FD-2` の中身。盤前の動きは 2026-11-01 ユーザー決定）:

| 担当 | 受け持つこと |
| --- | --- |
| **本システム** | **目的地の設定・経路再計算・中止の指示**（中止は、今の目的地・指示を捨てて止まって待たせる。2026-11-01 th-system の要求をユーザーが承認）。盤前では**その場旋回の角度**、**低速並進の左右と距離**、昇降機を上げたまま動くときの**速度と加速度の上限**を指示する |
| th-system | **経路の計画・走行制御・停止。**盤前の旋回と並進（クローラは横に動けないので、旋回と走行の組み合わせ）も th-system が制御する |

**本システムは th-system に対して人と同等の権限を持つ**（2026-11-01 ユーザー決定。`FD-12`）。
本システムの指示（目的地・経路再計算・発進）は、th-system では試験員の操作と同じに扱う。
**明示操作**は、th-system の「自律動作を許可しますか」で**「許可する」を押すこと**（th-system への明示操作。§1.2）と、**盤の選択**（本システムへの明示操作）。

**位置合わせの精度**（2026-11-01 ユーザー決定）: 旋回の角度の精度は、**不感帯を測ることで改善を見込む。**
旋回・並進で必要な精度が得られなかった場合は、**画像認識によるフィードバック修正**の導入を検討する。要る精度は未定（[Spec-open.md](Spec-open.md) `FK-V4`）。

**自律測定は、th-system の試験場内の動作（前日準備・盤前移動）とはほとんど別物になる**（2026-11-01 ユーザー決定。`FD-13`）。
ノウハウは活かすが、**準備なしで、地図を自動で作りながら作業をこなせるようにする。**

**画像からの推定（配置図・天面・中央までの距離）と、そのためのカメラの操作は ss-system が行い、本システムは欲しい情報を渡して結果を受け取る**（`FD-9`・`FD-10`）。
**天面の位置の推定は、天板四隅の吊り金具を手がかりにする方法を検証済み**（合成データでの検証。実物では未確認）。
方法と精度は検証レポート「[吊り金具による配電盤配置推定 検証レポート](https://claude.ai/artifact/A3Pz8dbXUn2srTn8NQFq2J)」（spec ではない。写さずにリンクする）。
自律測定は**これまでの技術**（走行系の自律走行・この推定）を応用する。
未定の残りは [Spec-open.md](Spec-open.md) `FK-S3`・`FK-S5`・`FK-V4`。

### 1.2 画面の入口

**走行系（th-system）の画面を主とし、そこからカメラの画面と本システムの画面へ移れるようにする**
（2026-10-30 ユーザー決定。**本システムだけでなく全体に関わる判断**）。
th-system・hve-system 側の画面と仕様の変更が要る（[Spec-open.md](Spec-open.md) §1）。

**自律測定は、th-system のメインメニューの「自律測定」ボタンから入る。**押すと「自律動作を許可しますか」と出て、**「許可する」を押したことが th-system への明示操作**になり、th-system は本システムからの指示を受けるモードに入る（2026-11-01 ユーザー決定。th-system 側の決定に合わせた。th-system [Spec-measure.md](../../../../th-system/docs/plan/spec/Spec-measure.md) §1。`FD-12`）。**許可しただけでは動き出さない。**
モード中の th-system の画面の「測定機能の画面へ」は、画面を移るだけ。
**立会試験中の測定の入口**（盤前で th-system の試験画面から本システムの画面へ移る）は未定（[Spec-open.md](Spec-open.md) `FK-U2`。th `O-a6`）。

本システムの画面（2026-11-01 ユーザー決定）:

| 項目 | 決まっていること |
| --- | --- |
| 置き場所 | **th-system とは別のポート** |
| 操作性 | **あたかも th-system の中にいるような、近い操作性にする** |
| 抜け方 | **th-system のほかの画面と同じく、いつでも抜けられる** |
| 本システムの起動中の th-system の画面 | 基本は表示されないが、**非常停止等のヘッダー・本システムへ移るボタン・本システムの終了ボタン**を置く |

ヘッダーに何を含めるか・本システムの画面での非常停止の置き方と異常の知らせ方は未定（[Spec-open.md](Spec-open.md) `FK-U1`・`FK-U2`）。

### 1.3 測るもの

**膜厚測定と板厚測定の 2 つ。どちらも同じ操作でできるようにする**（2026-10-30 ユーザー決定）。

| 項目 | 決まっていること | 出典 |
| --- | --- | --- |
| 測り方 | **測定器を測る面に垂直に押し当てて測る** | 2026-10-30 ユーザー決定 |
| 最初に測る面 | **天面から目指す**（ほかの面は後） | 同上 |
| 測定器 | **高価で購入できないので、モックアップで再現する** | 同上 |
| モックアップが再現するもの | **概形と、接触の検知**の 2 つだけ | 同上 |
| モックアップでの測定値 | **値は扱わない。**測り終えたら「**値を保存しました**」と示して済ませる | 同上 |
| **測定機構でできること** | **昇降機に取り付き、昇降機と一緒に上下する。測定器を前後に動かせる。左右には動かせない**（左右はクローラのその場旋回で合わせる。§1.1.2） | 2026-10-31 ユーザー決定 |

測る点の数は §1.1（立会は中央 1 点、自律は四隅と中央の 5 点）。「四隅」を縁からどれだけ内側にとるか・精度・本物の測定器での結果の残し方は未定（[Spec-open.md](Spec-open.md) `FK-S2`・`FK-V1`）。
測定機構の**設計は未定で、構成機器は変わりうる**（案は [arm.md](../arm.md)。spec ではない）。**できること（上の表）は決まった**（2026-10-31）。
**天面へ押し当てる最後の動き（最終アプローチ）の機構は検討中**（2026-11-01。昇降機は自重で下がるので、昇降機を下げて押し当てるとたるむ。[Spec-open.md](Spec-open.md) `FK-A5`）。

### 1.4 製品への接触

**製品に触れるのは本システムの測定器だけ**（2026-10-30 ユーザー決定）。

| 項目 | 決まっていること |
| --- | --- |
| 接触を行うのは | **本システム。**th-system の走行系は製品に接触しない（th-system の G1「物への接触 0 件」は走行系についてそのまま成り立つ） |
| 接触してよいもの | **測定器だけ。**腕・機体・昇降機など、測定器以外は製品に接触させない |

押し当ての力の上限と、測定器以外が当たらないことをどう保証するかは未定（[Spec-open.md](Spec-open.md) `FK-X4`・`FK-V3`）。
