# Spec-auto — 自律測定の移動の決まり

[Spec.md](Spec.md) §1.1.2 の詳細。**実装（ノード名・トピック名・アルゴリズム）は書かない。**
流れ（配置図 → 盤の選択 → 移動 → 盤前で測る）と移動の役割分担は [Spec.md](Spec.md) §1.1.2、th-system 側の振る舞いは th-system [Spec-measure.md](../../../../th-system/docs/plan/spec/Spec-measure.md)。
盤前で腕を起こしてから格納するまで（測定機構の制御）は [Spec-arm.md](Spec-arm.md)。

**ここの決まりは 2026-11-04 ユーザー決定**（本システムの実装管理担当の提案を承認。自律測定の移動の詳細設計を、測定機構の確定を待たずに始めるため）。
**値は暫定で、あとで調整する**（[Spec-open.md](Spec-open.md) `FK-V1`・`FK-V5`・`FK-X7`）。

## 1. 測定機構との境目

**移動の側が測定機構の側から受け取るのは、盤ごとの立ち位置・腕が格納位置にあるか・盤前の作業の結果（済み／測れなかったとその理由）の 3 つだけ**にする。

| 項目 | 決まり |
| --- | --- |
| 立ち位置 | **1 盤につき 1 か所。**5 点は旋回だけで合わせる（左右は旋回で合わせる。[Spec.md](Spec.md) §1.1.2）。盤面から機体の中心まで 0.389 m 以上は今までどおり |
| 立ち位置を決めるもの | 測定機構の側（腕が届く距離。`FK-V1`）。移動の側は受け取って動くだけ |
| 届かない点 | **その点だけ「届かず」と残し、立ち位置を変えに行かない**（立ち位置を変えるには腕の格納と並進が要るため） |
| 並進 | **最初の版では使わない**（暫定。盤前の並進で機体を盤に当てない条件 `FK-X7` が決まっていないため）。盤から盤へも目的地の指示で動く |

## 2. 配置図

| 項目 | 決まり |
| --- | --- |
| 作り始めるきっかけ | **新しい明示操作は足さない。**th-system で「許可する」を押したあと、**本システムの画面が開いたら自動で始める** |
| 始める前に確かめること | 腕が格納位置にあること・昇降機の原点が取れていること（取れていなければ先に原点取りの下降をする。[Spec-arm.md](Spec-arm.md)） |
| 探す方向 | **全周。**カメラで見られない方向は機体を回して補わず、配置図に「見ていない方向」として示す |
| 盤の正面 | 吊り金具では表と裏を区別できないので、**認識したときに機体に向いていた辺を正面とみなす**。ss-system が「正面が分かっている」印を付けて返した盤（背中合わせの盤など）は、**その正面を参考程度に使う**（正面の決め方は変えない。2026-11-05 ユーザー決定） |
| 回る順 | 同じ向きで隣り合う盤（列）ごとに**正面に向かって右から**。列が複数あるときは、今いる所に近い列から |
| 着いて認識し直したとき | 認識し直した位置で、その盤の配置図を直す |
| 走行中の認識し直し | **最初の版ではしない**（着いてからの認識し直しで足りるかを試験で見る。`FK-S5`） |
| もう一度探す | 盤が見つからないときなどのために **「もう一度探す」を置く。**押せるのは、指示待ちで腕が格納位置にあるときだけ |

## 3. ss-system への依頼

| 項目 | 決まり |
| --- | --- |
| 座標 | **依頼した時点の機体を基準にする**（機体の中心・床・前向き）。本システムが、その時点の th-system の自己位置で地図の座標に直す |
| 返るもの | 盤ごとに**天面の矩形（中心・高さ・向き・幅・奥行き）と確からしさ。**見つからないときは空の一覧と理由（ss-system [Spec.md](../../../../ss-system/docs/plan/spec/Spec.md) §1.1） |
| 依頼の終わり | ss-system は**「結果」と「後片付けの完了（カメラと昇降機から手を離した）」を分けて返す** |
| 終わるまで | **後片付けの完了を受けるまで、本システムは昇降機を動かさず、th-system にも動く指示を出さない**（`FD-11`。座標の基準はこれを前提にする） |
| 取り消し | 本システムは依頼を取り消せる。取り消されたら ss-system は後片付けをして完了を返す |
| 完了が来ない | 一定時間内に完了が来ない・ss-system と通信できないときは、**全体を止めて人を待つ**（§6） |

## 4. 走行と昇降の排他（`FK-X1`）

| 項目 | 決まり |
| --- | --- |
| 動き出す前 | **昇降機が下端に着いていなければ、目的地も発進も出さない。**要れば先に自分で下げる（`FD-14`） |
| 下げずに動いてよい移動 | **無し**（長さの上限 0。暫定。`FK-V5`）。盤から盤へも毎回下げる |
| 走っている間 | **昇降機が下端から 50 mm 以上離れたら「停止」する**（暫定。走行の揺れを実機で測って決め直す。`FK-V5`） |
| 止め方 | **「停止」（一時停止。目的地は残す）。**再開は §5 |
| 盤前のその場旋回 | 今の決まりどおり、高さで止める対象から外す（[Spec.md](Spec.md) §1.1.2） |

## 5. 一時停止からの再開

**一時停止からの再開は、いつも人の「走行」で行う。本システムが自分の判断で「発進」を出すことはしない。**
本システムが自分で出すのは、指示待ちからの新しい指示（目的地・旋回）だけ（どれも th-system の発進前の確認を通る）。

| 場面 | 振る舞い |
| --- | --- |
| 人が本システムの画面の「走行」を押した | 発進を送る。**昇降機が下端にいることを確かめてから**送る（下端になければ下げてから） |
| §4 で止めた・状態が読めなくなった（§7）・回復フォルト・通信途絶・人の割り込み | 人の「走行」を待つ |

## 6. 測れない・たどり着けないとき（`FK-S3`）

| 扱い | 場面 |
| --- | --- |
| **その盤を飛ばして次の盤へ**（理由を残す） | 経路が見つからない（`BLOCKED` が続き、経路の再計算を何回かしても解けない）／天面が見つからない／腕が振れる範囲が左右とも塞がっている／正面側の床が地図で塞がっていて立てない／着いて認識し直して求めた立ち位置が、今の位置から th-system の到着の許容差（±0.12 m／±0.12 rad）を超えてずれていて、目的地を 1 回出し直してもまだ超える |
| **全体を止めて人を待つ** | 腕が出たまま動けない（十分に上げられない・格納できない）／昇降機を下げられない／昇降機の高さか腕の状態が読めない（§7）／ss-system の後片付けの完了が来ない（§3） |

- お立会試験の「両側とも塞がっていれば測らずに止める」（[Spec.md](Spec.md) §1.1.1）は、**自律測定では「その盤を飛ばす」**と読む。
- 最後まで回ったら、**測れなかった盤とその理由を一覧で出し、人が選び直せる**ようにする。

## 7. 腕と昇降機の状態

| 場面 | 振る舞い |
| --- | --- |
| 昇降機の高さか腕の状態が読めない | **動く指示を出さない。**走っている間に読めなくなったら「停止」（§5） |
| **測定機構が付いていない**（hve-system が配信する。hve-system [Spec-module.md](../../../../hve-system/docs/plan/spec/Spec-module.md) §3） | **腕の条件は満たしているものとして移動してよい。**盤前の作業は「測定機構が付いていない」として飛ばす（測定機構なしで移動を試せる） |
| **異常が起きたときの人の対処**（2026-11-04 ユーザー決定） | **自律測定でも、人はジョグで機体（クローラ）を動かせ、腕はマニュアル操作で動かせる**（[Spec-arm.md](Spec-arm.md)）。**どちらも異常のときの対処用で、操作は人が責任を負う**。th-system は自律測定でも人のジョグを受ける（自己位置を見失ったあとも） |
| **腕が出ている間に人がジョグした** | **人の責任とする**（既知のリスク。2026-11-04 ユーザー決定）。th-system は自律測定では人のジョグを優先して受け、ジョグを拒む停止命令のような状態は無い。本システムの「停止」も指示待ちでは受けられないので、本システムからは止められない。ジョグのあとは §5 のとおり人の「走行」を待つ |
| 腕が格納位置にないときに抜ける | 本システムの画面で **「測定機構の腕が格納位置にあることを確かめましたか」と確かめる**（いつでも抜けられるのは保つ）。th-system の「自律測定を終了」には同じ確認を毎回出してもらう（th-system は腕の状態を知らないため。[Spec-open.md](Spec-open.md) §1.2） |

## 8. 画面の操作

| 項目 | 決まり |
| --- | --- |
| 盤の選択 | 配置図で選び（複数可）、**「開始」で確定する**（盤の選択が本システムへの明示操作。`FD-12`）。途中での追加・取り消しは最初の版ではしない |
| 停止・走行 | **本システムの画面に「停止」「走行」を置く**（人の割り込みのあとの「走行」もここ。th-system [Spec-measure.md](../../../../th-system/docs/plan/spec/Spec-measure.md) §7） |
| 中止 | 走っているなら止めて指示待ちにする。盤前の作業中なら腕を格納してから止める |
| 結果 | 測り終えた盤・測れなかった盤とその理由を一覧で出す |

## 9. 測り終えたあと・自己位置を見失ったとき

| 場面 | 振る舞い |
| --- | --- |
| 全部回り終えた | 昇降機を下げ、**最後の盤の前で指示待ちにする。**出発点には戻らない。自動では抜けない（[Spec.md](Spec.md) §1.2） |
| 自己位置を見失って非常停止した（th-system [Spec-measure.md](../../../../th-system/docs/plan/spec/Spec-measure.md) §4.3） | 地図と配置図は信用しない。**人が自律測定を抜けて入り直す**（地図も配置図も作り直す）。本システムの「走行」も受けない（見失ったことは、th-system が目的地を取り消して理由を返すことと、状態の「入り直しが要る」で知る。th-system も入り直すまで目的地・旋回・並進・発進を拒む。2026-11-04 th-system が反映。[Spec-open.md](Spec-open.md) §1.2）。**盤前で腕が出ている間に見失ったときは、人がジョグで向きを変え、腕のマニュアル操作で格納する**（本システムは旋回を出せないため。人の責任。2026-11-04 ユーザー決定）。測り終えた盤の結果は残す |
